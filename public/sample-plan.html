United GUARDIANS Automated Registration

How a member's registration travels from the web form into a Google Sheet and a Drive folder, with no manual data entry. Select any screenshot to view it full size.

  1. 1

    Members register on the web form

    A multi-wing form collects personal details, a photo, and the data privacy consent. After submitting, the member gets a receipt with a reference number to screenshot.

    • Web Ingestion
    • Frontend UI
  2. 2

    Apps Script receives and records each entry

    A serverless Google Apps Script handles every submission. LockService makes sure two members submitting at the same moment never overwrite each other, then the script writes a row to the matching wing's tab.

    • Google Apps Script
    • doPost handler
    • LockService
  3. 3

    Data and uploaded photos are stored automatically

    Each registration lands in the Google Sheets database while the member's photo is saved to a Google Drive folder, named with the same reference number so both records match.

    • Google Sheets DB
    • Google Drive API
